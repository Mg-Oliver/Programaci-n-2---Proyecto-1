## 🚀 Cómo Iniciar la Página de Presentación

Para iniciar el servidor de desarrollo local y abrir la página web interactiva:

```bash
cd presentacion-web
npm run dev
```

Luego abre en tu navegador:
👉 **[http://localhost:5173](http://localhost:5173)**

## 🎯 Secciones Diseñadas para la Exposición

1. **👥 Distribución de Temas para la Exposición (Grupo de 3):**
   - Tarjetas dedicadas para cada integrante con roles, clases a cargo, tiempo recomendado (3-5 min) y guión textual de qué decir frente al docente.

2. **🏗️ Arquitectura y Diagrama de Clases UML:**
   - Visualización modular de las 4 clases (`Main`, `CajaFuerte`, `Estadistica`, `UtilidadesConsola`).
   - Demostración de los 4 pilares: *Encapsulamiento*, *Composición Has-A*, *Multithreading (`Runnable`)* y *Responsabilidad Única (SRP)*.

3. **💻 Visor Didáctico del Código Java:**
   - Código completo con resaltado de sintaxis Java 21.
   - Puntos pedagógicos resaltados (ej: ¿Por qué `.equals()` y no `==`?, ¿Por qué atributos privados?, ¿Cómo funciona el hilo que oculta con asteriscos?).

4. **🎮 Simulador Interactivo de la Caja Fuerte:**
   - Emulador funcional en vivo idéntico al programa en consola.
   - Teclado restringido (1, 2, 3), bloqueo tras 3 intentos fallidos, cambio de contraseña y terminal ANSI interactiva.

5. **❓ Banco de Preguntas del Docente:**
   - Preguntas clásicas de examen y defensa con respuestas técnicas fundamentadas.

6. **📽️ Modo Diapositivas (Proyección en Clase):**
   - Diapositivas en pantalla completa con soporte de teclas de flecha (← / →) y notas del orador integradas.
